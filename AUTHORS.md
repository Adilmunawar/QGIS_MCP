# Authors

## Author and maintainer

**Adil Munawar** (adilmunawarx@gmail.com, [github.com/Adilmunawar](https://github.com/Adilmunawar))

Designed and wrote the toolbox: the Data Explorer dashboard with its sixteen
tabs, the live data engine (`qgis_mcp_plugin/connectors/`, `aoi.py`,
`monitor.py`), the toolbox, advanced and sensor command sets, the permission
profiles, approval queue, audit log and panel, the MCP tool surface, the
documentation and the test suites.

## Origin

The repository began as a fork of the MCP bridge by
[jjsantos01](https://github.com/jjsantos01/qgis_mcp) (MIT License). The
original socket bridge and the first project and layer commands came from
that work; they are acknowledged in `LICENSE` and `NOTICE`.
