[about]
about=Runs a localhost NDJSON socket server inside QGIS so an MCP client (Claude Desktop, Claude Code, Cursor, VS Code) can inspect, edit, analyse and render projects. Every command has a risk category; profiles decide what runs, what asks a person first, and what is refused. Live data commands stream Sentinel-2, Landsat and Copernicus DEM from public STAC catalogues, compute NDVI and other indices, pull weather and climate series, geocode places, and fetch OpenStreetMap and hazard feeds.
